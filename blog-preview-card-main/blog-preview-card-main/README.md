# 📌 Blog Card using Tailwind CSS

A modern and responsive **Blog Card Component** built using **Tailwind CSS**. 
The design is sleek, minimal, and optimized for various screen sizes.

# Live Demo : 

## 🚀 Features
- 📱 **Responsive Design** - Adapts to all screen sizes seamlessly.
- 🎨 **Modern UI** - Aesthetic card layout with shadow effects.
- ⚡ **Tailwind CSS** - No additional CSS required.
- 🏷️ **Category Tagging** - Labels for better content organization.

## 🛠️ Technologies Used
- **HTML5**
- **Tailwind CSS**
