# Simple Recipe Card UI 🍳

This project showcases a beautifully designed **recipe card UI** for a simple omelette recipe. The card contains an appealing layout with a recipe image, preparation time, and ingredient details.

## 🚀 Features  
✅ Modern and elegant card design  
✅ Responsive layout  
✅ Soft pastel color palette  
✅ Uses HTML & TailwindCSS only  

## 🛠️ Technologies Used  
- **HTML** - For structuring the recipe card  
- **TailwindCSS** - For styling and enhancing the design
