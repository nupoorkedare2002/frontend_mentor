# 🎴 Profile Card with Tailwind CSS

A responsive **Profile Card** built using **HTML** and **Tailwind CSS**. The card displays a user profile with an avatar, background patterns, and social stats.

![Screenshot 2025-03-04 120215](https://github.com/user-attachments/assets/bc0447f6-bf79-4997-84d2-867de0f81058)


## 🚀 Features

- Fully responsive design
- Modern UI using Tailwind CSS
- Beautiful gradient background
- Profile image with a floating effect
- Social stats section

## 🛠️ Technologies Used

- HTML
- Tailwind CSS
